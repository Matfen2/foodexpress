Architecture

Choix techniques

  • Event-driven - ApplicationEventPublisher avec @Async + @EventListener pour le découplage des effets de bord (notifications, logs)
  • State machine - Cycle de vie des commandes géré via OrderStatus avec transitions validées côté service
  • Gestion d'erreurs centralisée - @RestControllerAdvice : 404 ressource manquante, 422 règle métier, 400 validation, 500 catch-all
  • Migrations versionnées - Flyway V1 → V4, rejeu automatique à chaque démarrage
  • Pagination - Spring Data Pageable sur tous les endpoints de liste
  • Validation - Bean Validation (@Valid, @NotBlank, etc.) sur toutes les DTOs entrantes
